## Advanced Configuration

### Startup View

Configure which page is displayed on launch under **Settings → Startup → Startup View**. Choose from your preferred starting page — whether it's Live TV, EPG, VOD, or any other section — so ynoTV opens exactly where you want it every time.

### 40+ Themes
Customizing the look of your app:
- Explore 40+ built-in themes in **Settings > Themes**.
- Look for **Neon** and **Glassmorphism** options for a modern look.

### Startup Behavior
Configure your app to start exactly where you left off:
- **Remember Channels**: Reopen the last viewed channels on launch.
- **Multiview Reconnect**: Reassemble your last multiview layout automatically.

### Source Name in Search Results

When managing multiple IPTV sources, differentiating between channels with identical names across different providers can be challenging. Enable source identification in search results to improve channel selection accuracy.

**Configuration Path**
:   Navigate to **Settings → LiveTV → Search tab**

**Enable Display**
:   Toggle **Include Source Name in Search** to append the provider identifier to each search result

**Benefit**
:   Instantly identify which source a channel belongs to without manually checking, streamlining your search experience when working with multiple providers
