## Advanced Configuration

### Startup View

Configure which page is displayed on launch under **Settings → Startup → Startup View**. Choose from your preferred starting page — whether it's Live TV, EPG, VOD, or any other section — so ynoTV opens exactly where you want it every time.

### 40+ Themes
Customizing the look of your app:
- Explore 40+ built-in themes in **Settings > Themes**.
- Look for **Neon** and **Glassmorphism** options for a modern look.
- **OLED Black Background** renders dark-theme surfaces as **pure black** while keeping the accent color — great for OLED displays and saving power. It applies to the Dark & Dark Color themes in the V3 UI (and to custom themes via the matching OLED mode option: pure-black surfaces, no backdrop blur, flattened gradients).

### 24 UI Languages
ynoTV's interface is translated into **24 languages** — Arabic, Bosnian, Chinese (Simplified & Traditional), Croatian, Dutch, English, Farsi, French, German, Greek, Hindi, Hungarian, Italian, Polish, Portuguese (Brazil), Russian, Serbian, Spanish, Turkish, Ukrainian, Urdu, and Vietnamese. Switch any time under **Settings → Language**.

### Minimize to Tray
Enable **Settings → UI → Minimize to tray when closing** and closing the window hides it to the **system tray** instead of quitting — so live playback and scheduled recordings keep running. Use the tray icon to reopen the window or fully quit the app.

### Automated Backups
Never lose your setup. Under **Settings → Import/Export → Automated Backup**, ynoTV can automatically save a backup file at a regular interval — every hour up to every week — using the same format as the manual Export option:
- Pick the **backup interval** and how many backups to keep (1–20, oldest pruned automatically).
- Choose the **backup folder** (default or custom).
- **Back up now** saves instantly, and the **last backup time** is shown so you know it's running.

Restoring is just as easy: use **Import** in the same settings tab, and your sources, settings, customizations, watch history, local library entries, and more come back.

### Startup Behavior
Configure your app to start exactly where you left off:
- **Remember Channels**: Reopen the last viewed channels on launch.
- **Multiview Reconnect**: Reassemble your last multiview layout automatically.

### Source Name in Search Results

When managing multiple IPTV sources, differentiating between channels with identical names across different providers can be challenging. Enable source identification in search results to improve channel selection accuracy.

**Configuration Path**
:   Navigate to **Settings → LiveTV → Search tab**

**Enable Display**
:   Toggle **Include Source Name in Search** to append the provider identifier to each search result

**Benefit**
:   Instantly identify which source a channel belongs to without manually checking, streamlining your search experience when working with multiple providers
