Multiview allows you to monitor up to four streams at once, perfect for tracking multiple games or news cycles simultaneously.

## Layout Modes

ynoTV supports five distinct viewing modes:
1. **Main View**: Standard single-channel playback.
2. **Picture-in-Picture**: A large primary screen with a small secondary overlay.
3. **Side by Side**: Two 16:9 players side by side.
4. **Big + Bottom Bar**: A large main view with a horizontal bar for rapid secondary channel access.
5. **2x2 Grid**: Four equal-sized screens for balanced monitoring.

## Opening Multiview

Click the **Multiview button in the titlebar** to open the layout picker, choose a layout, and switch instantly. The picker shows the available layouts plus the **Viewer Engine** selection (below).

## Viewer Engine

Multiview can render its players with either of two engines, selected in the layout picker:

- **HLS (Default)** — an in-browser HLS player that supports on-screen overlays and uses less system resources.
- **MPV** — the embedded **libmpv** player, which also supports overlays and shares the MPV rendering pipeline.

HLS is the default engine — switch to MPV if you prefer the MPV rendering pipeline or need behaviors specific to the native engine. When you switch layouts, the chosen engine is remembered and applied to all multiview slots.

<Aside type="tip">
If you previously used multiple MPV instances and found them heavy, HLS mode reduces system resource usage while keeping overlay support.
</Aside>

## Using Multiview

### Adding Channels
1. Switch to a Multiview layout (Modes 2, 3, or 4).
2. Navigate the **Live TV** or **EPG** lists.
3. Right-click a channel and select **Send to Slot #** (e.g., Send to Slot 2).

### Interaction & Controls
- **Swap Screens**: Click on any secondary screen to instantly swap its stream with the main primary window.
- **Audio Control**: Each screen can be independently muted or unmuted.
- **Seamless Switching**: If you return to Main View and then back to a Multiview grid, ynoTV will resume playback of your previously viewed channels in their respective slots.

## Phone Remote Multiview Tab

The phone remote includes a **Multiview tab** that mirrors the desktop multiview:

- **Engine selector at the top** — pick **HLS** or **MPV** right from the phone; the desktop multiview switches to match (HLS is the default).
- **Layout picker** — choose any layout from the phone and the desktop view updates live.
- Slot changes and the currently playing streams sync back so the phone always shows what's on screen.

## Persistence & Startup

In **Settings** > **Startup**, you can enable advanced persistence:
- **Remember Last Viewed**: Automatically saves the stream playing in each screen.
- **Reopen Last on Startup**: If enabled, ynoTV will launch directly into your last used Multiview layout and autoplay all saved streams.

<Aside type="tip">
Use the numeric keys `1` through `4` to quickly toggle between different layout modes.
</Aside>
