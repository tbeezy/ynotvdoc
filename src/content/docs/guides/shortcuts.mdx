Efficiency is at the core of the ynoTV experience. Master these keyboard shortcuts to navigate the interface and control playback with ease.

<Aside type="tip">
All shortcuts are fully customizable. Navigate to **Settings** > **Shortcuts** to rebind any action to your preferred key — including mouse buttons.
</Aside>

## Shortcuts Overlay

Press **`/`** to open the in-app **shortcuts overlay**, a quick reference showing every current binding grouped by Playback, Navigation, Interface, and Layout. It always reflects your custom bindings, not just the defaults. Press **`/`** or **`Esc`** to dismiss it.

## Playback Controls

| Action | Default Key | Description |
|--------|-------------|-------------|
| **Play / Pause** | `Space` | Toggle playback state |
| **Mute / Unmute** | `M` | Toggle audio mute |
| **Seek Forward** | `→` | Seek forward in current stream |
| **Seek Backward** | `←` | Seek backward in current stream |
| **Select Subtitle** | `J` | Open the subtitle track selection modal |
| **Select Audio Track** | `A` | Open the audio track selection modal |
| **Toggle Fullscreen**| `F` | Enter or exit fullscreen mode |
| **Toggle Stats** | `I` | Show/Hide the playback statistics overlay |
| **Replay Last Stream**| `Q` | Replay the last stream you watched |

## Navigation & Discovery

| Action | Default Key | Description |
|--------|-------------|-------------|
| **Channel Up** | `↑` | Switch to previous channel |
| **Channel Down** | `↓` | Switch to next channel |
| **Focus Search** | `S` | Focus the search input in the title bar |
| **Close / Back** | `Esc` | Close current view or return to previous screen |
| **Back (Mouse Button)** | Mouse back button | Triggers the app's built-in "go back" navigation (close settings, stop playback, exit a view). Rebind or claim it for another action to free up the mouse back button. |

## EPG Shift

The **EPG Shift** button in the guide toolbar moves the entire EPG grid forward or backward by **one hour** at a time — handy when a provider's guide is offset or you want to preview what's airing later. The shift applies to the current guide view and can be reset from the same toolbar.

EPG shifting is also available as **controller buttons**: bind **EPG Next Hour (Guide > 1 hour)** or **EPG Previous Hour (Guide < 1 hour)** in **Settings → Controllers & Remote → Button Combinations** to shift the guide with your controller.

## Controllers & Remotes

Beyond the keyboard, ynoTV can be driven entirely by a **game controller** or your **phone**:

- **Game controller** — spatial navigation with the D-Pad, plus fully rebindable buttons and **chord combos** (hold L1/R1/L2/R2 + button). Configure in **Settings → Controllers & Remote**.
- **Keyboard as Controller** — bind keyboard keys to act as controller buttons, so an HTPC wireless keyboard remote drives the same spatial navigation and chords.

See the [Controllers & Phone Remote](./controllers-phone-remote/) guide for the full setup.
