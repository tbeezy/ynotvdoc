ynoTV now includes dedicated support for Stremio add-ons, allowing you to extend your streaming experience with community-built content sources and utilities. A dedicated **Strem** page has been added to the app for managing everything Stremio-related.

## Getting Started

Navigate to the **Strem** page and click **Manage Add-ons** to browse and install your Stremio add-ons directly within ynoTV.

### Addon URL

Instead of clicking *Install to Stremio* on an add-on's website, copy the **Copy Link / manifest.json** link and use that URL to add it manually in ynoTV.

## Strem Settings

### Stream Picker Mode

Choose how streams are handled when playing a movie or series:

- **Show Picker** — Displays a list of available sources so you can select which one to play.
- **Auto-play** — Automatically plays the first direct stream link when a movie or series is selected, skipping the picker for a faster experience.

## Hide the Strem Tab

If you don't plan on using Stremio add-ons, you can hide the **Strem** tab entirely. Go to **Settings → Navigations** and toggle the Strem tab off.
