## Troubleshooting Guide

**Source not syncing or channels giving error but not in other players?** Try adding a user-agent in the source setting. An example one: `TiviMate/4.7.0 (Allwinner Nitro Pro; Android 12)`

If you run into any issues, please [open an issue](https://github.com/tbeezy/ynotv/issues) on GitHub.
