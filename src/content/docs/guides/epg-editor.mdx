The **EPG Editor** allows you to fine-tune your channel data and Electronic Program Guide display. It provides tools for overriding broken logos and ensuring your guide remains accurate and visually consistent.

## Custom Logo Overrides

If a provider's channel logo is missing, low-resolution, or outdated, you can easily override it.

## How to Use the EPG Editor

To access the EPG Editor, right-click any channel and select **Edit EPG**. This opens the editor for the selected channel, where you can customize the following:

### Channel Configuration

- **TVG-ID Assignment**: Map the channel to a different XMLTV identifier to correct or change the program guide source
- **Logo Override**: Replace the default channel logo with a custom image URL
- **EPG Time Shift**: Adjust the guide data forward or backward to account for timezone differences or schedule offsets

### Program Management

In the **Programs** tab, you can directly manage the Electronic Program Guide data:

- Edit existing program details
- Remove unwanted entries
- Add new programs manually
- Undo accidental deletions

### EPG Search & Assignment

The **EPG Search** feature enables you to:

- Search through available TVG-IDs across all configured sources
- Assign the channel to a different EPG source by selecting an alternative TVG-ID
- When **All Sources** is selected, you can map the channel to EPG data from any available source in your configuration

### Per-Channel EPG Source Override

Using EPG Search, a channel's EPG can be **overridden to pull data from a different LiveTV source** — for example, giving a channel a TVG-ID from a provider whose guide is more accurate. The override **persists across every subsequent sync**, so re-syncing won't reset it. The **Source** tab of the editor also lets you browse a source's channels and jump straight to editing any of them (channels with active overrides are marked with a dot).

### Automatch Missing

The **Automatch Missing** tab matches every channel that doesn't have an EPG assignment in one batch:

- **Scope** — match a single source, or **All Sources** at once.
- **Match Against** — match by **M3U names** (your channel list) or raw **EPG names** from the XMLTV data (for providers that don't include TVG-IDs).
- **Categories** — narrow to all categories in the source or a specific set.
- **Minimum Match Threshold** — only auto-apply matches that score at least this percentage; lower values produce more matches but less accuracy.

Run **Auto-Match Missing in Source** and watch the progress as channels are scored and matched, with a matched/total count and skipped channels. Matches at or above the threshold are applied automatically — individual fine-tuning can still be done in the Channel tab afterward.
