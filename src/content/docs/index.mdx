ynoTV is a modern, feature-rich FOSS IPTV player built with Tauri and React. Stream live TV, manage multiple sources, record shows, and track your favorite sports teams.

## Supported Sources

- **M3U/M3U8** - Standard playlists from URL or file
- **Xtream Codes** - Full API support with VOD and Series
- **Stalker Portal** - MAC address authentication
- **EPG Only** - Standalone XMLTV guide data
